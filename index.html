Why “wicked”?

No single cause.
No single owner.
No finish line.

In 1973 the planners Horst Rittel and Melvin Webber called some problems “wicked”: problems that resist a clean definition and have no final solution. Extreme heat is one of them.

  1. There is no single cause to fix

    Heat arrives through land, bodies, cities and wallets at the same time, and each system pushes on the others.

  2. Every solution changes the problem

    Air conditioning cools a room and heats the street. Shifting work to cooler hours protects one worker and cuts another’s wages.

  3. There is no finish line

    Each hotter season resets the problem. Protection has to be kept up, not achieved once.

  4. It lands unequally

    The same heatwave is an inconvenience for some and a catastrophe for others. The difference is protection, not temperature.
