# Authentication

Common Shade (https://beattheheat.asia) needs none. It is a static, read-only website: every page and file is open, and there is no login, key, token or OAuth flow. Nothing here asks an agent to act on anyone's behalf.

- Open files: https://beattheheat.asia/openapi.json
- Guide for agents: https://beattheheat.asia/for-ai/
- Privacy: https://beattheheat.asia/privacy/
