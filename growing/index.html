    How this record works

    • One record, growth.json, holds every change; both views and the text for AI systems are built from it. Each change traces to the pull request that made it.
    • "Why it matters" is our reading. "What the source says" is quoted from the source, and the build checks that the quotation appears in the site's own records.
    • A changed file is not progress by itself. Changes are reviewed by a person before they are recorded; nothing is counted twice because it appears on several pages.
    • Publication dates come from growth-dates.json, with how each date is known. Dates looked up online are from Crossref or the page's own metadata; an "online by" date is never shown as a publication date.
