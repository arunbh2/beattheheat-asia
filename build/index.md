# Build protection

Choose a place, add actions, and see which cycles they could help interrupt, what each depends on, and what they leave untouched. Nothing here is a recommendation: it is a way to think a package through, together.

## How to read this

- **Could help interrupt, never will fix**A cycle turns green when an action works on one of its links. Whether it breaks in a real place depends on everything listed under what it depends on.

- **Evidence shown for every piece**Each action carries its evidence level, from design concept to independently evaluated, with its source.

- **No recommendations**The portfolio view shows balance and blind spots. It never recommends an organisation or a grantee.

- **Saved in the address**Your package lives in the page address, so you can bookmark it or share it. Nothing is sent to us.
